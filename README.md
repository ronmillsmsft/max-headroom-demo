## What's Inside

- **8 narrated slides** with Azure AI Speech (neural TTS)
- **CSS-animated Max Headroom** — no images, pure CSS art
- **CRT monitor aesthetic** with scanlines, glitch effects, and retro styling
- **Real stats** pulled from live databases (11 agents, 24+ hours saved, 74 conversations)

## Built With

- GitHub Copilot CLI + Max Headroom AI assistant
- Azure AI Speech (text-to-speech narration)
- Azure DevOps, Microsoft Planner, SharePoint, PowerPoint integrations
- Python, SQLite, Playwright browser automation
- Pure HTML/CSS/JS — no frameworks

## The Story

Ron Mills is a CMI Program Manager who partnered with Max Headroom (a persistent AI assistant in GitHub Copilot CLI) to automate his daily workflow. Together they built 11 specialized agents that handle access approvals, meeting prep, release notes, and more — saving 24+ hours of manual work.

The key insight: **you don't need to be a developer to build with AI.** Ask questions, try things, let AI handle the details.
